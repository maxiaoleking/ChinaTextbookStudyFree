# 内容质量审计与语文阅读升级

审计日期：2026-09-24。范围：本地四科题库、语文课文与故事、前端实际使用的数据及判分逻辑。本文是按小学语文教研标准进行的数据审读，不是实际特级教师签审，也不是对全部题目逐题正确性的担保。

2026-09-28 已完成全部188篇语文扩展阅读的替换，配套题由564道增加到936道（增加372道），图片与所需朗读齐备。[本地阅读入口](http://localhost:3000/content-revision.html)。逐篇篇幅、能力标签及媒体校验结果见 [全量验收结果](content-revision-results.json)；[首批样例清单](content-revision-samples.json)保留最初6篇试制记录，后续修订以全量结果为准。

## 结论

升级前的核心问题是故事明显偏短、题组偏重直接提取、部分选择题多解或选项重复，以及真实存在的判分错误。本轮重点处理了这些问题，阅读题增加了语境词义、推断和表达等层次。整套题库仍适合继续试用打磨，不能直接宣称达到优质同步教辅的质量：知识点名称不统一、课程被切得过碎、核心点变式题不足的问题仍在。

## 语文阅读难度

以下为升级前的比较：正文汉字数，不含标点、题目；课文取 `prose` 和 `story`。新版逐篇校准进一步排除被归入 story 的短篇文言文，不把古诗、儿歌或文言文的字数当成现代叙事故事标准。各年级上下册合并计算中位数。

| 年级 | 叙事课文中位字数 | 旧故事中位字数 | 比例 | 旧故事数 |
| --- | ---: | ---: | ---: | ---: |
| 一 | 133.5 | 73.5 | 55.1% | 32 |
| 二 | 312.5 | 126 | 40.3% | 32 |
| 三 | 444 | 231 | 52.0% | 32 |
| 四 | 585 | 303.5 | 51.9% | 32 |
| 五 | 637 | 343.5 | 53.9% | 32 |
| 六 | 795.5 | 411.5 | 51.7% | 28 |

188 篇故事全部只配 3 道题。旧提示词限定一年级 4—6 句、六年级 14—20 句，没有参照真实课文，最终倾向生成很短的、只够支持直接找答案的小故事。

长度不等于难度。抽读六上《老巷里的丁香信使》，还出现“积蓄着破茧而出的逻辑”等不自然表达，以及直接谈“分号”“标准答案”的教学腔。复杂词汇不能替代真实的人物动机、事件发展与值得品味的细节。

本次采用的编辑标准（项目建议，不是教育部规定字数）：

- 每篇以同册、同单元的适合文体课文为参照，正文汉字数为参照的 90%—115%。排除含识别占位符的参照。
- 低年级采用具体事件、清楚因果、自然常用词；中年级增加心情变化、前后照应和语境词义；高年级增加人物选择、含蓄情感、结构与表达效果。
- 不把课文改名改人物后当原创，不硬塞知识点、成语与说教；篇幅合格但情节、语言或题目不合格仍须返修。
- 一二年级每篇 4 题，三四年级 5 题，五六年级 6 题。覆盖提取、词义、真正的推断；三年级起加入表达效果，五年级起加入结构。单元要素另由编辑审查。
- 判断最多一道；填空明确要求原文和确切字数；推断与赏析采用唯一答案选择题。开放表达将来需独立评价机制，不能直接拿一个标准句做字符串判分。
- 每题记录支持答案的句序号和能力标签；解析必须解释证据如何支持答案。干扰项来自合理误读，控制选项长度，避免正确项总在 A 或总是最长。

当前所有 550 篇语文课文的 `unitNumber` 均为空。流程优先用明确单元编号，其次匹配单元大纲点名的课文，无法匹配时明确记录“整册叙事课文回退”。这仍不等于完成了教材篇目与单元的人工核对，后续应补齐映射。

本轮188篇中，68篇匹配到大纲点名课文，2篇使用核实后的同单元现代叙事课文，118篇使用整册叙事参照。因此“篇幅校准”表示与实际课文参照接近，不表示188篇均已完成人工逐单元对齐。

从整册编排看，纸船、水沟、雨天、修补物件等选材仍较集中，并有4组跨篇同名标题（含六上第四单元相邻两篇同名）。单篇文本通过审读不代表整套选材足够丰富。后续应按年级配置校园、家庭、运动、动物、历史、科学观察等选材比例，并结合学生试做检验真实难度；不能只继续增加字数或题量。

## 题量是否到位

| 学科 | 单元数 | Web 练习题 | 当前小课数 | 只有一道题的小课 | 源文件额外 exam 题 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 数学 | 106 | 2,438 | 376 | 6 | 2,438 |
| 语文 | 94 | 2,154 | 816 | 501 | 2,152 |
| 英语 | 48 | 1,102 | 555 | 421 | 1,096 |
| 科学 | 37 | 851 | 419 | 255 | 850 |

四科 Web 共 6,545 题，语文约 22.9 题/单元。总量可以支持初步体验，但无法用总量证明覆盖充分：语文 61.4% 小课只有一道题，无法可靠判断学生掌握程度。英语、科学也存在严重碎片化。

`build-data.ts` 只将 `unit_test.questions` 拆成课时，`exam.questions` 的 6,536 题未进入 Web 学习流程。因此不能把源文件总题数当成学生实际可练习题数；也不应未经去重和审核就全部追加。

大纲知识点按名称精确匹配时，语文 29/299 项没有同名题，英语 75/160、科学 85/197。这个数字表示“尚未对齐”，不能直接认定是真缺题：有不少题使用了更细或不同的知识点名称，前端把它们建成了额外小课。

建议先统一知识点 ID、归并同义标签，再进行能力覆盖表审查。项目首轮目标可设为：核心知识点准备 6—10 道有效变式，单次练习抽 4—6 道，另留平行测验；低频简单点可以少些。阅读按篇组织，不强行拆成孤立单题。推荐“每单元两篇完整阅读”作为首轮配置；先让 188 篇有效，再考虑增加篇数。

## 已确认并修复的问题

- 9 道题：2 处答案掺入 `and` 导致无法对应选项；重复选项；题干直接泄露读音；“32 人租船”原题存在两种坐满方案；英语比较级存在两种正确译法；关联词题的问法、选项及答案不一致等。
- 数学“最接近20”原题列出了20，却把18当正确答案。已改成明确的大小比较题。
- 共享选择题判分原先把答案首字母 A—D 当成选项号，误判 `apple`、`a+3`、拼音等；此外大小写归一化会提前匹配到错误选项。对当前 3,278 道可由选项文本定位答案的题，旧逻辑有 90 道“选中正确选项仍判错”。修复后，正确及其余错误选项均通过回归检查。

故事阅读也已接入相同的共享判分逻辑，覆盖选项、判断、文字填空的正确/错误/空答案检查。本次修复仅针对 Web 使用的题和 TypeScript 共享判分逻辑；源 `exam` 题库及 iOS 独立 Swift 判分实现未全量审查、未同步修改。旧数据与修改清单保存在本地 `data/content-revision/backup/` 和 `question-fixes.json`。

## 图片、音频及内容发布

按指定模型分工：故事与独立审读使用 `openai/gpt-6-luna`；插画使用 `meta/muse-image`；缺失朗读使用 `google/gemini-3.8-flash-lite-tts`。模型不自动换成其他厂商或版本。

GPT-6 Luna 的直接输出是文本，因此负责正文、题目及插画描述，图像单独调用 Muse。[OpenAI 模型说明](https://developers.openai.com/api/docs/models/gpt-6-luna)、[Muse 模型说明](https://openrouter.ai/meta/muse-image)。

语音采用少量稳定的预置音色：低年级 Leda，中高年级 Sulafat。两者是 Google 文档列出的音色；最终适合程度仍需试听。指定 Gemini 模型在实际请求中只接受 PCM 输出，按 24kHz、单声道、16-bit PCM 转为真实 Opus，避免文件扩展名与编码不符。[Google 语音说明](https://ai.google.dev/gemini-api/docs/speech-generation)。

原先“课文缺8句音频”不是准确的补音任务：这8条是独立标点或占位片段。2026-09-28 已对照教材处理扫描发现的19处异常，涉及13篇课文：补全《扁鹊治病》《景阳冈》跨页截断，归回《小狗学叫》误接到《那一定会很好》后的正文，修复拟声字及引号断句。保留8处原书有意填空、古文字图示或模糊电话号码，添加阅读说明，并明确从听读/跟读音频中排除。原页缺失的5张图片也已从项目原教材来源补回。

《小狗学叫》恢复完整正文后，同单元两篇待生成故事的参照字数由749更新为1272，避免以截断课文作标准。修改记录和原文备份见 `data/content-revision/passage-repairs.json` 与 `backup/passages/`。当前扫描无 `[?]` 或独立标点异常，不表示全部779篇课文已逐字对照原页。

四上第八单元另纠正了文体参照错误：不能用49字的文言文《王戎不取道旁李》限定现代叙事故事，改以同单元《扁鹊治病》等现代叙事课文作参照。两篇扩展阅读已重新生成。该排除规则已加入后续计划生成及回归检查。

插画逐张核对全文中的场景、关键动作和物体关系，严重不符时重画；复杂的连续动作若反复失真，则选取正文中清楚、完整的另一时刻。图片复查按实际 JPEG 哈希和对应正文指纹缓存，正文或图片变化后重新检查。

排除这类片段后，实际使用字段中另发现并补齐了一条中文选项音频“中华不振，主权丧失”。后续题目与故事改写产生的新音频分别重新生成。

## 本轮最终验收

- 188篇、936道配套题均已进入Web；正文、题目、当前审核记录、配图版本与页面构建结果一致。逐篇正文处于计划要求的参照篇幅范围内。
- 188张最终Muse插画通过当前正文和实际JPEG哈希对应的模型场景审查，另对异常图片进行了编辑查看；不等于人工教师逐图签审。
- 9,186个媒体引用无缺失；最终故事实际使用的8,993个不同音频文件均确认可解码且为Opus。本轮共生成9,515个不同音频文件，包含返修缓存和首批样例，均通过编码、正时长与粗略语速异常筛查；没有逐条人工试听。另修正2个历史MP3内容误用.opus扩展名的文件，保留原始备份。
- 3,278道单元选择题和1,226道中英文故事题通过正确、错误、空答案回归；8项生成约束测试、TypeScript类型检查与差异格式检查通过。
- 188个阅读页面及每篇的图片、首句音频共564个HTTP请求全部成功；实际浏览器点验年级筛选、逐句朗读启动、进入答题及正确判分，截图保存在本地生成记录中。
- 全库规则扫描：0个规则标记、0条缺失音频、0处无效课文片段；8处原书填空/图示明确不朗读。这个结果只证明扫描规则通过，不证明全部题目语义无误。

## 可复现流程

```bash
# 全量结构审计（无需密钥）；详尽结果包含规则线索，不等于错误清单
python3 scripts/content_audit.py

# 全量续跑：生成、审核、返修、媒体、分批替换；失败项保留旧版
.venv-tts/bin/python scripts/stories/run_revision.py --workers 12 --audio-workers 24
# 可另开一个终端更新本地进度页面
.venv-tts/bin/python scripts/stories/revision_dashboard.py --watch

# 或分步执行：建立188篇计划；默认生成每年级一篇样例
python3 scripts/stories/revise.py plan
python3 scripts/stories/revise.py generate
python3 scripts/stories/revise.py review
python3 scripts/stories/revise.py repair
python3 scripts/stories/revise.py review

# 仅对通过当前版本审核的故事生成媒体，支持断点续跑
.venv-tts/bin/python scripts/stories/revision_media.py images
.venv-tts/bin/python scripts/stories/revision_media.py audio --include-audit

# 文字稳定后核对每张插画，实质不符时用 Muse 重画
.venv-tts/bin/python scripts/stories/review_images.py --repair --workers 8

# 全部所选故事须审核通过且图片、音频齐备才可替换；原数据先备份
python3 scripts/stories/revise.py apply
npm run build:data --workspace=china-study-free

# 回归检查
node_modules/.bin/tsx scripts/check-choice-grading.ts
node_modules/.bin/tsx scripts/check-story-grading.ts
.venv-tts/bin/python scripts/stories/verify_revision.py --all --decode --images
npm run type-check
```

全量入口为 `run_revision.py`，分步入口则用 `generate --all`。生成结果、原始尝试、审核与返修记录、图片提示词、语音清单和调用用量保存在被 Git 忽略的 `data/content-revision/`。新故事使用 `-v2` ID，避免把旧故事完成记录或配图误用到新文本。

状态以本地生成记录和最终交付说明为准。AI 独立审读只是一道筛查，必须结合样例人工阅读；要作为同步教辅正式推广，还需要真实教师复核以及学生试做后观察错误率、耗时和干扰项选择情况。

## 本轮发现并修复

- `g4up-u1-kp1` 第 19 题的答案是“亿”，但旧界面只给数字键盘。现在数字类题若答案需要文字或多个空，自动提供文字输入，保留原题答案、音频和判分语义。
- `english-g5down-u4-kp22` 第 19 题需要完整输入 `thirty-first`，旧输入限制为 10 个字符。现在支持完整答案、PC 键盘、手机字符按钮、长答案换行。数字输入也提供真实输入框；分数、负号、百分号答案按实际需要提供额外键。
- 旧数字判分只读数值前缀，可能把 `1/2` 与 `1/3` 都当成 1，把 `2,4` 合并成 24。现在完整解析数值、分数、百分数和有序多空，明确检查单位，不删除任意文字。精确分数比较保留小数容差，并防止大整数丢失精度。配对题拒绝重复、缺项或多余垃圾输入。全部 6,545 练习题和 1,226 故事题通过正确/错误/空输入回归。
- 15 个单元已有知识资料却被手册漏掉：原代码猜测连续 `kp1..kpN`，而实际课程有跳号或追加知识点。现在按该单元真实课程 ID 读取。`/book/science-g1up/guide/2/` 应显示 2 条资料。手册进度条可以缩小，避免多张卡片挤出手机屏幕。
- 数学数据包含 JSON 转义损坏、非法 `bdiv`、没有 `$` 的分数选项和未转义填空下划线。现在按实际命令修复后渲染：循环小数的点仍用 `dot`，分数仍用 `frac`，除号仍用 `div`；4,936 个真实公式片段全部通过 KaTeX 实际解析。未知未来公式保留文字回退，长公式可在局部横向滚动。
- 当前 JSON 引用的媒体中，1,787 个 `.opus` 实际是 MP3，42 个 `.jpg` 实际是 PNG。完整发布包还包含旧媒体，合计 5,269 个 MP3 和 105 个 PNG 后缀不匹配。打包按文件头写 MIME 清单；发布仅核对特殊对象并修正错误的 S3 元数据，保留文件字节、缓存与其他元数据。正确对象不会再次上传。上线验证检查完整特殊对象清单，并检查公开 HTTPS 的 MP3 / PNG 响应。

选择题里 `He/he`、`Saturdays/saturdays` 等大小写差异是正常干扰项，不能在数据扫描中按小写合并。数据扫描发现 88 个选择题正确选项高亮与判分不一致的样本，该项由交互测试分支单独修复并验证。

## 仍需内容层面审阅

完整性通过不代表所有题目都达到教学质量要求。1,498 课没有知识讲解；1,183 课只有 1 道题，数量与产品注释中的每课 5–7 道不一致。这些课程可以使用，但不宜宣称知识覆盖和练习量已全部到位。

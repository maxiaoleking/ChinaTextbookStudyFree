# AWS Web 部署

当前线上地址：**https://d3nmsqi4n72idj.cloudfront.net**

2026-10-02 使用 AWS CLI 部署本地生产版本。架构是东京（ap-northeast-1）的私有 S3 桶加 CloudFront HTTPS。使用 AWS 提供的域名，无需 EC2、Lightsail、域名或业务后端。CloudFront 使用按量计费和覆盖日本的 PriceClass_200，未创建 WAF、付费证书或托管数据库。

## 资源

- CloudFormation 栈：`china-textbook-web`，区域 `ap-northeast-1`
- S3：`china-textbook-web-772081360719-ap-northeast-1`
- CloudFront：`EP0AZ0PJ3E2HM`
- CloudFront OAC 仅允许该分发读取 S3；S3 保留全部公共访问阻止设置。
- CloudFront Function 将目录路由转成 `index.html`，支持直接打开或刷新课文、课程、故事详情。
- HTTP 自动跳转 HTTPS；媒体按真实文件类型设置 `audio/ogg`、`audio/mpeg` 等响应类型，允许范围请求；麦克风权限限本站。
- S3 设置保留策略：删除 CloudFormation 栈不会删除学习资料。

## 更新

```sh
npm run build
python3 scripts/deploy/prepare-site.py --destination deploy-output/site-YYYYMMDD
python3 scripts/deploy/aws-static-site.py --site deploy-output/site-YYYYMMDD
python3 scripts/deploy/verify-site.py --site deploy-output/site-YYYYMMDD
```

打包工具拒绝覆盖已有部署快照，扫描 OpenRouter 密钥格式，按白名单排除备份、源文件与本地配置，并核对 JSON 中的媒体引用。部署工具使用项目独立的资源，默认东京区域，不修改 AWS 默认区域或其他项目。`--upload-only` 复用基础设施；上传可安全重试，完成后清除 CloudFront 缓存。输出状态、文件清单保存在被 Git 忽略的 `deploy-output/`。

大量小音频文件首次上传较慢，可通过任务专用 AWS 配置文件提高 `s3.max_concurrent_requests`；无需修改全局配置。更新时 `s3 sync` 仅上传变化文件，不自动删除旧对象。带内容哈希的 JS 与音频缓存一年，图片缓存一小时，数据缓存五分钟，页面要求重新验证。

## 数据与体验

当前部署快照 `site-border-countdown-20261003` 共 144,291 个文件，4,029,534,898 字节，44 册教材。音频文件共 132,657 个，含保留的 81,017 个原文件及 51,640 个当前 Web 使用的 MP3；另有 472 张故事图片和 1,582 张教材页面图片。所有数据中的媒体引用检查通过；媒体备份和 `.env` 不进入部署包。

2026-10-03 修复手机语音兼容：当前 Web 教学与 UI 语音采用实际 MP3 及 `audio/mpeg`，避免较老 iOS 对 Ogg/Opus 的格式限制。转换保留当前声音与内容，没有调用付费模型；原 Opus 保留供旧页面和 native AAC 打包使用。旧错题中保存的 Opus 路径优先读取对应 MP3。Web 构建需要 Python 3 和带 `libmp3lame` 的 FFmpeg，校验缓存后不会重复转码。详见 [手机语音兼容修复记录](ios-web-audio-fix-2026-10-03.md)。

PC 采用侧栏和宽屏阅读布局，手机采用底部导航和单列阅读。故事详情使用专门的阅读/答题操作栏，避免底部导航遮挡“开始答题”。阅读操作栏和年级选择页包含手机安全区域间距。首次选择年级时隐藏底部导航，避免“继续”被遮挡。教材学习路径会测量容器宽度，调整蛇形位置，保持 80 像素课程按钮；窄屏课程结算卡片可以收缩；空答案时“跳过”可以正常进入解析并继续下一题。

2026-10-03 更新课程讲解：每页首次收听期间禁用“下一步”或“开始练习”。按用户最新要求，按钮不显示秒数或“先听讲解”附加文字；蓝色光环从顶部中心沿圆角边框顺时针走一圈，跟随真实音频进度。多段讲解全部自然结束后解锁，缓冲不会推进光环，切页或暂停不会被当作听完。本次讲解中返回已听页面可立即继续。从教材点击进入课程时预先准备同一个音频播放器，后续翻页复用播放器并自动播放。已移除底部“点击播放讲解”和播放提示行；首次直接打开链接若被浏览器拦截，则在页面首次点击/触摸或按 Enter/空格时恢复播放，也可点标题旁的小喇叭；播放失败可重试或阅读后继续，静音时也提供阅读后继续。未知音频时长仅显示淡色边框，不估算进度。讲解期间不保存答题会话，刷新不会将未完成讲解误判为已经进入练习。

学习进度保存在当前浏览器，不跨设备同步。跟读录音只在浏览器内录制与回放，不上传 AWS；当前没有语音识别评分。录音需要浏览器支持、用户允许麦克风和 HTTPS。真实 iPhone/Android 的麦克风权限与音频播放仍需真机复核。

## 成本

此方案没有 $7.50/月的服务器固定费用，按 [S3 存储与请求](https://aws.amazon.com/s3/pricing/) 和 [CloudFront 流量等](https://aws.amazon.com/cloudfront/pricing/)实际使用量付费。本次兼容音频新增约 1.84 GB，当前快照约 4.03 GB；没有新增服务器、数据库或付费语音生成调用。此前约 2.19 GB 的存储估算不再代表当前资源量；旧版本保留、请求及下载流量也会影响账单，实际费用以 AWS 计费为准。免费额度由整个账号共享，未自动创建预算告警或邮件通知。

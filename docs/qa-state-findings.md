## 正常和边界覆盖

- 年级切换保留 XP、错题、心数与会话；购买余额不足、错误道具 ID、未拥有装备、重复购买及装备持久化。
- 每日登录奖励重复领取与重新加载、周末双倍 XP、每日目标幂等、v0/v6 数据迁移、70 天历史修剪至 60 条。
- 连续学习、同日重复活动、漏学日护盾消耗、里程碑幂等；宝箱按单元稳定定位与领取标记幂等。
- 连续扣心到 0、五分钟补心、离线多周期恢复；错题按课程隔离、去重、答错重置和共享 SRS 调度。
- 空答案不提交；连续十次检查/继续只处理一次；新旧会话恢复、负数/超大题目索引、最后一题刷新结算。
- 计时的前台/后台、失焦/恢复、离页尾段 flush、关闭计时、长期闲置上限、点击/键盘/滚动恢复、重复同时间 tick、卸载清理。
- 每日时限的关闭、阈值前/正好/超过、昨天数据、午夜释放、同课继续、另一课被阻止、达到上限后禁止重开、按钮快照后的再次检查。
- 实际错题页与移动导航徽标对过期/今天/明天/之后的统计一致；未来复习不计入今日待办；未完成 hydration 时不闪现徽标。
- 周报的周日归属、周一午夜换周、与上周差额、同一天缓存及次日今天标记；以仅移除日期依赖的内存旧版回放稳定复现两处旧错误。

## 验证边界

组件集成脚本执行的是实际源码中的处理器和 effect；视觉、触觉、音效和动画调度使用替身。它不代替真实 React 页面、音频播放、PC/mobile 排版或实际页面 reload 的浏览器检查。旧会话没有最后题目答案时使用中性“这题已完成”反馈，避免猜测结果。

浏览器禁用持久存储或空间耗尽时可以继续当前会话，但关闭浏览器后无法保证未写入的进度仍存在。未在此记录中验证跨浏览器同步或两台设备并发；项目目前没有服务端进度同步。
